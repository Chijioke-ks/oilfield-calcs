# oilfield-calcs
Open-source Python toolkit and Streamlit app for basic  well-operations calculations (cement volumes, hydrostatic pressure, pump hydraulics, decline forecasts).
In scope
• Volumes and hydrostatics: pipe and annular capacities, fluid volumes, hydrostatic pressure, multi-fluid columns.
• Cementing: slurry volume with excess, sacks, mix water, displacement, pump time, end-of-job differential pressure.
• Coil tubing: internal volume, annular velocity, bottoms-up time, pump time.
• Pipe flow: velocity, Reynolds number, friction factor, pressure drop for Newtonian fluids (power-law fluids as a stretch goal).
• Decline curves: Arps exponential, hyperbolic, and harmonic models, curve fitting, and EUR.
• Deliverables: tested library, deployed app, README with worked examples and a validation table.
# Out of project scope:
• Deviated wells (assume vertical, so TVD equals MD).
• Temperature and pressure effects on slurry and fluid density.
• Gas migration, multiphase flow, and annular eccentricity.
• Coil tubing buckling, lockup, and fatigue life.
• Real-time data, and any proprietary or confidential numbers.
• Use as certified design software. Label it educational and preliminary estimation.
